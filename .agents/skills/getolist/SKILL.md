# getolist — 스터디 Olist 자료 받기

사용자는 인자 없이 $getolist만 부른다. 아래 명령 하나만 실행하고 그 요약을 전달한다.

## 절차

1. 저장소 루트(`harness.toml`이 있는 폴더)에서 실행한다:

   uv run t2s fetch olist

   명령은 인자를 받지 않는다. 받는 곳과 해시는 `src/t2s/fetch/olist_study.json`에 고정돼 있다. 이미 있고 해시가 맞는 파일은 건너뛰므로 여러 번 불러도 된다. 끝까지 가면 10줄 이내 요약과 라이선스 표기를 출력한다.

2. 종료 코드 0이면 출력된 요약을 그대로 사용자에게 보여 준다. 줄여 쓰거나 해석을 덧붙이지 않는다.

3. 종료 코드가 0이 아니면 `중단 N단계:` 줄과 그 아래 조치 줄을 그대로 보여 주고 멈춘다.
   - gh 로그인이 안 됐거나 저장소 접근 권한이 없으면 사용자에게 `! gh auth login`을 안내하고 멈춘다. 로그인을 대신하지 않는다.
   - 받기 실패(`gh N`)면 한 번만 다시 $getolist를 부른다. 두 번째도 실패하면 더 시도하지 말고 사용자에게 보고한다.
   - 해시 불일치면 다시 부르지 않는다. 원격 자료가 바뀌었거나 손상된 것이며, 어떤 파일이 다른지와 다음 할 일을 사용자가 정한다.

## 받은 뒤

- 이 스킬은 DB 등록·준비(값 색인·열 프로파일)를 하지 않는다. 쓰려면 사용자가 $connect에 `data/olist/olist.db`를 주면, $connect가 밖으로 나가는 것을 알리고 승인을 받은 뒤 등록한다.
- `data/olist/schema.snapshot.json`의 `notes`·`logical_relations`는 사람이 쓴 설명이라 퓨어 조건(AGENTS 규칙 9)에서는 모델에 주지 않는다.

## 하지 말 것

- `gold/` 아래 파일과 `.part`·`.rejected-*` 파일을 열어 보거나 내용을 터미널에 출력하지 않는다(정답 SQL·기대 결과가 들어 있다).
- `src/t2s/fetch/olist_study.json`의 커밋·해시를 고치거나, 해시를 건너뛰는 옵션·환경변수를 더하지 않는다. 해시가 다르면 멈추는 것이 맞는 동작이다.
- 다른 사본(TS 하네스 등)에서 파일을 복사해 오지 않는다. 이 스킬은 원격에서만 받는다.
- 스터디 저장소에 쓰지 않는다(이슈·PR·커밋 금지). 읽기만 한다.
