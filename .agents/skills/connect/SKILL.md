# connect — 데이터셋 보기·붙이기·바꾸기

사용자는 $connect 뒤에 아무것도 안 쓰거나, 파일 경로나 이름만 말한다. 명령 인자를 사용자에게 치라고 하지 않는다. 모든 명령은 저장소 루트(`harness.toml`이 있는 폴더)에서 돌린다.

## 무엇을 할지 고르기

- 말이 없다 → "목록".
- `.sqlite`·`.db` 같은 파일 경로를 말했다 → "새 SQLite 붙이기".
- `bird`, "버드", "BIRD"를 말했다 → "BIRD 붙이기".
- `olist`, "올리스트", "Olist"를 말했다 → "Olist 붙이기".
- `use <이름>` 또는 목록에 있는 이름을 말했다 → "바꾸기".
- 어느 쪽인지 모르겠으면 "목록"을 보여 주고 한 줄로 묻는다. 추측하지 않는다.

## 목록

   uv run t2s datasets

출력을 그대로 보여 준다.

## 새 SQLite 붙이기

1. 이름을 정한다. 사용자가 말한 이름을 쓰고, 없으면 파일 이름에서 만든다(소문자로 시작, 소문자·숫자·밑줄·하이픈). 만든 이름을 사용자에게 알린다.
2. 먼저 고지를 받는다:

   uv run t2s register <이름> --sqlite <경로>

   이 명령은 등록하지 않고 고지문만 출력하며 종료 코드 3으로 끝난다. 고지문(밖으로 나가는 것, 다른 프로그램이 쓰고 있지 않아야 함, 민감한 DB 금지, 부속 파일 주의)을 그대로 보여 주고 "진행할까요?"를 묻는다.
3. 사용자가 진행하라고 답한 뒤에만:

   uv run t2s register <이름> --sqlite <경로> --yes
   uv run t2s prepare <이름>
   uv run t2s use <이름>

   `prepare`가 "임베딩 모델이 없다"로 멈추면 "모델 파일 417MB를 받아야 합니다"라고 알리고, 사용자가 좋다고 하면 `uv run t2s fetch model`을 돌린 뒤 `prepare`부터 다시 한다.
4. 끝으로 `uv run t2s datasets` 출력을 보여 준다.
5. 사용자가 거절하면 아무것도 하지 않고 끝낸다.

## BIRD 붙이기

   uv run t2s prepare bird-minidev
   uv run t2s use bird-minidev
   uv run t2s datasets

`prepare`가 "자료 없음"으로 멈추면 "먼저 $getbird로 BIRD 자료를 받아야 합니다"라고 알리고 멈춘다. 이 스킬이 대신 받지 않는다. 처음 준비는 약 2분이 든다.

## Olist 붙이기

1. 목록(`uv run t2s datasets`)에 이미 `olist`가 있으면 "바꾸기"로 간다.
2. 없으면 `data/olist/olist.db`가 있는지 파일 존재만 확인한다(열지 않는다). 없으면 "먼저 $getolist로 Olist 자료를 받아야 합니다"라고 알리고 멈춘다. 이 스킬이 대신 받지 않는다.
3. 있으면 이름 `olist`, 경로 `data/olist/olist.db`로 "새 SQLite 붙이기"의 2단계부터 한다(고지 → 승인 → 등록·준비·전환). 승인 없이 등록하지 않는다.
4. `data/olist/` 아래 다른 파일(모델 입력, 평가셋 manifest, 스키마 스냅숏)은 쓰지 않는다. 스냅숏의 사람이 쓴 설명은 퓨어 조건(AGENTS 규칙 9)에서 모델에 주지 않는다.

## 바꾸기

   uv run t2s use <이름>

출력을 그대로 보여 준다. "준비 안 됨"이나 "낡음"이 나오면 `uv run t2s prepare <이름>`을 돌릴지 묻는다.

## 지우기

사용자가 "등록 지워줘"라고 할 때만:

   uv run t2s register --remove <이름>

## 하지 말 것

- 사용자 승인 없이 `--yes`를 붙이지 않는다. 한 번 승인받은 것은 그 DB 하나에만 해당한다.
- DB 파일을 직접 열어 내용을 보거나 바꾸지 않는다. 다른 도구로 스키마를 읽지 않는다.
- `harness.toml`을 고치지 않는다. 등록은 `var/state.json`에 적힌다.
- `gold/` 아래 파일과 `data/bird-minidev/download/` 아래 파일을 열거나 내용을 출력하지 않는다.
- 종료 코드가 0도 3도 아니면 마지막 오류 줄을 그대로 보여 주고 멈춘다. 같은 명령을 되풀이하지 않는다.
