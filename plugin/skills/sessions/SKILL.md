# sessions — 세션 보기와 이어 돌리기

사용자는 /sessions만 부른다. 이 스킬은 `p3 sessions`, `p3 status`, `p3 report`, `p3 resume`, `p3 stop`만 부르고 그 출력을 전달한다. 세션 폴더(`.text2sql/sessions/<세션 이름>/`)의 파일을 열어 요약하지 않는다.

준비: 이 스킬은 엔진 스킬의 실행 스크립트로만 일한다. 이 SKILL.md가 있는 폴더의 옆 폴더 `p3-engine`의 `scripts/p3`를 `sh`로 부른다(`sh <이 SKILL.md가 있는 폴더>/../p3-engine/scripts/p3 <명령>`, 아래에서 `p3 <명령>`이라고 줄여 쓴다). 사용자가 지금 일하는 폴더(작업 폴더 `.text2sql/`가 있는 폴더)에서 부르고, 명령 인자의 상대 경로는 그 폴더 기준이다. 명령 출력에 `t2s <명령>`이라고 나오면 `p3 <명령>`으로 읽는다. 작업 폴더(`.text2sql/`)가 없다고 나오면 `p3 init`을 돌릴지 한 줄로 묻는다. `p3`가 `no_uv`(uv 없음)나 `setup_failed`(처음 환경 만들기 실패)를 돌려주면 그 메시지를 그대로 안내하고 멈춘다. 스킬 이름은 `/이름`으로 적었다. Codex에서는 `$이름`, 플러그인으로 깔았으면 `/text2sql:이름`으로 부른다.

## 무엇을 할지 고르기

- 목록 요청("세션 목록", "뭐 돌렸었지", "아까 돌린 거") → "목록".
- 한 세션의 진행이나 결과 요청("어제 run 보고 다시", "그거 결과", "진행 어때") → "한 세션 보기".
- 이어 돌리기 요청("멈춘 거 이어서") → "이어 돌리기".
- 멈춤 요청 → "멈추기".
- 자리 질문("어디 있어", "폴더가 어디야") → "자리 알려 주기".
- 말이 없으면 "목록"으로 간다.
- 세션 이름을 말하지 않았는데 한 세션이 필요한 일이면 먼저 `p3 sessions`를 돌려 목록을 보여 주고 어느 세션인지 한 줄로 묻는다. 추측하지 않는다. 사용자가 "가장 최근 것"이라고 했으면 목록에서 그 일에 맞는 종류(한 세션 보기·이어 돌리기·멈추기는 `set`)의 가장 위 세션을 쓴다.

## 목록

   p3 sessions

출력을 그대로 보여 준다. 첫 줄은 세션 폴더의 자리이고, 그 아래로 최근 것부터 한 줄씩(이름, 종류, 데이터셋, 상태, 라벨 요약) 20개까지 나온다. 종류는 `set`(묶음 실행), `ask`(질문 하나), 지표 길의 세션(`metric`, `explore`, `check`, `diagnose`, `define`)이다. 점수가 있는 줄의 라벨 전체 문자열을 자르지 않는다. "세션이 없습니다"면 그대로 알린다.

## 한 세션 보기

종류가 `set`인 세션만 아래 명령으로 본다. `ask`와 지표 길의 세션은 목록의 줄과 세션 폴더의 자리만 알려 준다.

   p3 status --run-id <세션 이름>

   p3 report --run <세션 이름>

진행 질문이면 status, 결과 질문이면 report를 부르고 출력을 그대로 보여 준다. 라벨 전체 문자열과 "새로 맞음·새로 틀림" 문장을 자르지 않는다. "아직 채점 전입니다"나 "아직 생성 중입니다"가 나오면 그 줄을 보여 주고 멈춘다(채점은 /runset이 한다). "정답 없음: 채점 생략"이 나오면 그 아래 실행 요약을 그대로 보여 준다.

## 이어 돌리기

   p3 resume --run-id <세션 이름>

출력을 그대로 보여 준다. "이어 돌 수 없습니다"로 시작하는 거절 줄이 나오면 그 까닭을 그대로 보여 주고 멈춘다(채점한 세션, 코드 판이 다른 세션, 옛 run 폴더의 run은 이어 돌 수 없다). 명령은 분리된 프로세스를 띄우고 바로 돌아온다. 끝날 때까지 기다리지 않는다.

## 멈추기

   p3 stop --run-id <세션 이름>

출력을 그대로 보여 준다.

## 자리 알려 주기

`p3 sessions` 첫 줄의 세션 폴더 자리와 세션 이름을 이어 `<세션 폴더>/<세션 이름>/`으로 알려 준다. 안의 파일을 읽어 요약하지 않는다.

## 지킬 것

- `.text2sql/gold/` 아래 파일, 받은 zip(`.text2sql/data/*/download/`), 공개 evidence 파일(`.text2sql/data/bird-minidev/hints.public.json`)을 열거나 내용을 출력하지 않는다.
- 사용자에게 명령 인자를 치라고 하지 않는다.
- 기본은 evidence not_used(퓨어 조건: 문항의 evidence와 사람이 쓴 설명을 모델에 주지 않는다)다. 사용자가 evidence(문항 조건)를 주라고 말했을 때만 used로 돈다.
- 새 DB는 밖으로 나가는 것을 알리고 승인을 받은 뒤에만 등록한다. 민감한 DB에 쓰지 않는다.
- DB 파일을 직접 열거나 DB 클라이언트·다른 도구로 스키마를 읽지 않는다.
- 세션 모델이 SQL을 직접 쓰지 않는다. SQL은 `p3 ask`·`p3 run`이 만든다.
- 점수 라벨을 줄이지 않는다. 백엔드·evidence 방식·경로가 다른 점수끼리 우열을 말하지 않고, 원 논문·리더보드·스터디 E0 점수를 덧붙이지 않는다.
- 모델을 알 수 없으면 돌리지 않고 묻는다.
- 채점한 run은 이어 돌릴 수 없다. 같은 run을 두 번 시작하지 않는다.
- 커밋과 푸시는 사용자가 말할 때만 한다.
- 플러그인 폴더와 엔진 스킬 폴더에는 아무것도 쓰지 않고, 엔진 소스를 읽지 않는다. 자료와 기록은 `.text2sql/`에만 생긴다.
- run 폴더의 `records.jsonl`·`items/` 같은 큰 파일을 통째로 읽지 않는다.

## 하지 말 것

- 세션을 지우거나 이름을 바꾸거나 옮기지 않는다. 세션 폴더 안의 파일을 고치지 않는다.
- 세션 폴더의 `records.jsonl`, `report.md`, `report.json`, `ex.jsonl`, `items/`, `calls/`, `session.json`, `t2s-log.jsonl` 같은 파일을 열지 않는다. 명령 출력만 쓴다.
- `p3 sessions`·`p3 status`·`p3 report`·`p3 resume`·`p3 stop` 밖의 명령을 부르지 않는다. 새로 돌리거나 채점하는 일은 /runset, 질문 하나는 /text2sql이 한다.
- 점수 라벨을 줄여 쓰지 않는다. 백엔드·evidence 방식·경로가 다른 세션끼리 우열을 말하지 않는다.
